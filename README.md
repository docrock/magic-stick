# The Magic Stick Rig

The parts list for building a full YouTube studio on one stand.

**Live page:** https://docrock.github.io/magic-stick/
**Video:** https://youtu.be/8DHIAdi_sPk

One stand, four things bolted to it, nothing to tear down when you finish. Camera, mic, monitor and light, carried in one hand at about 22 lb total. Every part has alternates at three budgets, because the best version of this rig is the one you build out of what is already in your closet.

## What's in here

- `index.html` is the whole page. Self contained, fonts embedded, no build step and no dependencies.
- `.nojekyll` tells GitHub Pages to serve the files as they are instead of running them through Jekyll. Leave it alone.

## Updating it

Edit `index.html`, commit, push. GitHub Pages rebuilds on its own in a minute or two.

## About the links

Product links are Amazon affiliate links using tag `infophreak-20`. They point straight at `amazon.com/dp/ASIN` with no shortener and no redirect in between, which is both the cleanest thing for readers and the safest thing for the affiliate account.

Note: Amazon's Associates agreement prohibits affiliate links in email. Newsletters should link to this page, and this page carries the links.
